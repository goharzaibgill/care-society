**Superior Care Society Website**


A modern, responsive, and animated website designed for the Superior Care Society to manage and showcase social welfare activities including student support, charity work, blood donation camps, and volunteer engagement.


**Features**


- Modern Landing Page with animations  
- Team Page (Executive + Members)  
- Donation System UI  
- Volunteer Registration Form  
- Blood Donation Section  
- Projects / Activities Showcase  
- Contact Page  
- Professional Video Section (Muted Autoplay)  
- Fully Responsive Design  
- Smooth Scroll and Hover Animations  


**UI / UX Design**


- Primary Color: Dark Blue  
- Accent Color: Gold  
- Background: White  
- Clean and minimal professional layout  
- Smooth animations and hover effects  
- Modern typography (Poppins / Inter)  


 **Pages Structure**

- Home (Landing Page)  
- About Us  
- Projects / Activities  
- Donate  
- Volunteer  
- Blood Donation  
- Request Help  
- Team Page  
- Contact Us  



**Team Module**


- Executive Team (President, Secretary, CTO, Coordinators)  
- Full Members List  
- Department-wise organization  
- Hover animations on cards  
- Responsive grid layout  



**Video Section**


- Autoplay enabled  
- Muted by default  
- Loop support  
- Responsive design  
- Smooth fade-in animation  


**Tech Stack**


- HTML5  
- CSS3  
- JavaScript  
- Bootstrap / Tailwind (optional)  
- Animation libraries (AOS / custom CSS animations)
